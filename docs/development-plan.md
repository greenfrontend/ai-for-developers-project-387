# План развития

Этот репозиторий продолжает приложение календаря звонков из предыдущего
проекта. Продуктовая база уже перенесена, поэтому следующие задачи стоит
оформлять через GitHub issues, разбирать агентом и доводить до pull request.

## Фичи

- Настройки доступности: разрешить администратору задавать рабочие дни, часы и
  исключения для конкретного типа события.
- Отмена бронирования: добавить публичную ссылку для отмены записи и страницу
  подтверждения отмены.
- Уведомления: отправлять участнику и организатору письмо после создания или
  отмены бронирования.
- Часовой пояс гостя: показывать слоты в локальном часовом поясе пользователя и
  сохранять исходный часовой пояс в бронировании.

## Баги и улучшения надежности

- Двойное бронирование: усилить защиту от гонки, когда два гостя выбирают один
  слот почти одновременно.
- Валидация email: унифицировать проверку email на фронтенде и бэкенде.
- Пустые состояния: проверить все страницы администратора и гостя на понятные
  сообщения при пустых списках и ошибках API.
- Миграции: добавить проверку идемпотентности миграций в CI.

## Процессные задачи для этого проекта

- Настроить OpenCode GitHub App и проверить, что агент отвечает в issue.
- Создать issue с triage-разбором одной фичи и одного бага из этого плана.
- Провести PR через цикл: агент делает правку, ревью оставляет замечания, агент
  вносит доработки.
- Добавить scheduled workflow с ночной проверкой Lighthouse и загрузкой отчета
  в GitHub Actions artifacts.
